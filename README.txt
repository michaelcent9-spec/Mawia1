MAWIA — THE BIRTHDAY ISSUE
A responsive three-page editorial birthday website using the six supplied images.

FILES
- index.html: magazine cover / introduction
- birthday.html: birthday message, countdown and Arcane-inspired portrait gallery
- afterdark.html: luxury-car finale using both supplied car photographs
- style.css: shared responsive styling
- script.js: birthday countdown
- assets/: four Arcane-inspired portraits and two car photographs supplied for this project

PUBLISH WITH GITHUB PAGES
1. Upload all files and the complete assets folder to the repository root.
2. In GitHub, open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select main and /(root), then Save.

All images are local assets. No stock-photo substitutions or external image dependencies are used.
